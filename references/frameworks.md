# Framework References

The series uses complementary security and AI governance perspectives rather than treating any one framework as the complete AI security architecture.

- **OWASP GenAI / LLM security** — the LLM/application security layer.
- **MITRE ATLAS** — adversarial AI/ML tactics and techniques.
- **NIST AI RMF** — broader AI risk-management structure.
- **AI BOM thinking** — inventory, provenance and traceability across AI components.

These references are used in the source series as complementary lenses with different boundaries.
